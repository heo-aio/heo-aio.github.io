## 📖 About

문법을 외우고 끝내는 대신, 실습 코드를 다시 읽으며 **헷갈렸던 지점 → 왜 그런지 → 다음에 확인할 것** 흐름으로 정리합니다.
정해진 커리큘럼을 따라가는 기록이라기보다, 그날그날 배우고 부딪힌 걸 계속 쌓아가는 **진행형 로그**입니다. 그래서 카테고리도 계속 늘어날 예정입니다.
